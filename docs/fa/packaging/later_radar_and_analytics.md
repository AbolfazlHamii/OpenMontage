# برنامه‌ی بعدی (هنوز ساخته نشده): رادار ویدیوهای داغ و حلقه‌ی آمار یوتیوب

طبق دستور کار، این دو ابزار تا وقتی کانال درآمد داشته باشه صبر می‌کنن.
این فقط برنامه است، کدی نوشته نشده.

## ۱. رادار موضوع‌های داغ (viral candidate radar)

**هدف:** هر هفته یه فهرست کوتاه از موضوع‌هایی که الان توی جامعه‌ی
فارسی‌زبان سر و صدا دارن، با نمره‌ی همون معیار موضوع
(`lib/fa_packaging.score_topic`)، تا تصمیمِ «ویدیوی بعدی چی باشه» با داده
گرفته بشه نه با حدس.

**منبع‌ها (به ترتیب ارزونی):**
1. پیشنهادهای خودکار جستجوی یوتیوب برای «تاریخچه …» و «داستان …» (رایگان؛
   از ایران معمولاً فقط با پراکسی).
2. YouTube Data API v3 (رایگان با سهمیه‌ی روزانه): ویدیوهای فارسیِ هفته‌ی
   اخیر در این ژانر، و «ویدیوهای پرت» (بازدیدی خیلی بیشتر از اندازه‌ی کانال)
   = نشونه‌ی تقاضا.
3. Google Trends برای ایران (احتمالاً ۴۰۳؛ یک بار امتحان، بعد رد شو).
4. خبرهای فناوری فارسی (زومیت، دیجیاتو) برای «بهانه‌ی خبری»: معرفی محصول،
   رکورد ارزش بازار، رسوایی.

**خروجی:** `docs/fa/packaging/radar/<تاریخ>.json` با ۱۰ موضوع و شواهد هر کدوم
(لینک و عدد)، و یه خلاصه‌ی فارسی. مدل ارزون (`classification`) فقط برای
دسته‌بندی؛ نمره‌ی نهایی و تصمیم با عامل و صاحب کانال.

**هزینه‌ی تخمینی:** نزدیک صفر (API رایگان + چند سِنت مدل ارزون در هفته).

**ریسک‌ها:** موضوع داغ ≠ موضوع همیشگی؛ رادار فقط زمانِ انتشار رو جلو یا
عقب می‌بره، نه هویت کانال رو. موضوع‌های سیاسی خودکار علامت ریسک می‌گیرن.

## ۲. حلقه‌ی آمار یوتیوب (YouTube Analytics feedback loop)

**هدف:** بعد از هر ویدیو، آمار واقعی برگرده توی پروژه تا ویدیوی بعدی از
روی نتیجه ساخته بشه، نه از روی قانون‌های کلی.

**چی خونده می‌شه (YouTube Analytics API، با اجازه‌ی OAuth خودِ صاحب کانال):**
- نمایش (impressions)، نرخ کلیک، و میانگین مدت تماشا، **به تفکیک منبع
  ترافیک** (جستجو، صفحه‌ی اصلی، پیشنهادی، شورتس، خارجی).
- منحنی ماندگاری (کجا بیننده‌ها رفتن) — کنار نقشه‌ی صحنه‌ها و متن.
- «بیننده‌های جدید / گاه‌به‌گاه / همیشگی».
- نتیجه‌ی Test & Compare (این یکی API نداره؛ از استودیو دستی وارد می‌شه).

**کجا می‌ره:**
- `retros/<تاریخ>-<پروژه>.md` در دفتر کانال (`channel-bible`) — با یه جمله
  «چی یاد گرفتیم».
- یه خط در `docs/fa/packaging/results.tsv` برای هر ویدیو: عنوان، تامبنیل
  برنده، CTR و مدت تماشا در ۷ و ۲۸ روز.
- منحنی ماندگاری برای `fa_script_lint` و مهارت روایت (که الان با داده‌ی
  کانال‌های دیگه کار می‌کنن).

**قاعده‌ها:**
- هیچ‌وقت تصمیم رو روی آمار ۲۴ ساعت اول نگیر؛ ۷ و ۲۸ روز.
- عدد هر ویدیو فقط با ویدیوهای خودِ کانال مقایسه بشه، نه با «میانگین
  اینترنت».
- کلید OAuth فقط در `.env` / فایل محرمانه‌ی صاحب کانال؛ هیچ‌وقت در مخزن.

**چرا الان نه:** با ۱–۲ ویدیو عددها نویزند، و تا مسیر حساب پرداخت معلوم
نشه، تنظیم OAuth روی کانالی که ممکنه عوض بشه کار اضافه است. شروعِ پیشنهادی:
بعد از ویدیوی پنجم یا پذیرش در YPP، هر کدوم زودتر.

**هزینه‌ی تخمینی:** API رایگان؛ کار ساخت حدود یک جلسه.
