# راه‌اندازی آپلود خودکار یوتیوب (یک بار برای همیشه)

با این کار، زیرنویس‌ها، عنوان، توضیحات، تگ‌ها و کامنت هر ویدیو از پوشه‌ی `SPOIL\NNN_...` مستقیم می‌رن روی یوتیوب و دیگه لازم نیست دستی توی Studio وارد بشن.

این مراحل رو **خودتون** انجام می‌دید، چون ورود به اکانت گوگل با خودتونه. حدود ۱۵ دقیقه طول می‌کشه و هزینه‌ای نداره (کارت بانکی لازم نیست).

## قبل از شروع

- **v2rayN روشن**، با همون سرور همیشگی. کنسول گوگل کلاد از ایران خطای 403 می‌ده.
  - اگه با VPN روشن هم 403 دیدید (تست ۲۰۲۶-۱۱-۰۶ همین رو نشون داد)، توی v2rayN حالت **TUN** رو روشن کنید یا سرور یه کشور دیگه رو امتحان کنید. اگه باز هم نشد، به من بگید.
- با **همون جیمیلی وارد بشید که کانال @spoilfa زیرشه**. شناسه‌ی کانال باید `UCzcS-uRF9p36KmjzAWiEGqA` باشه. اگه می‌خواید ویدیوها برن روی یه کانال دیگه، قبل از شروع به من بگید.
- بهتره از همون پروفایل کروم که مخصوص کاناله استفاده کنید.

## ۱. ساختن پروژه

1. برید به `console.cloud.google.com`.
2. اگه شرایط استفاده رو نشون داد، کشور رو انتخاب کنید و قبول کنید.
3. بالای صفحه، کنار لوگوی Google Cloud، روی انتخابگر پروژه بزنید ← **New Project**.
4. اسم پروژه: `spoil-publisher` ← **Create**.
5. بعد از چند ثانیه، از همون انتخابگر، پروژه‌ی `spoil-publisher` رو انتخاب کنید. بقیه‌ی مراحل باید داخل همین پروژه انجام بشن.

## ۲. روشن کردن YouTube Data API v3

1. منوی ☰ ← **APIs & Services** ← **Library**.
2. جستجو کنید: `YouTube Data API v3`.
3. روش بزنید ← **Enable**.

## ۳. صفحه‌ی رضایت (OAuth consent screen)

اسم جدیدش توی منو **Google Auth Platform** هست. منوی ☰ ← APIs & Services ← **OAuth consent screen** ← **Get started**:

1. **App Information**: اسم اپ `SPOIL publisher`؛ ایمیل پشتیبانی: جیمیل خودتون ← Next.
2. **Audience**: گزینه‌ی **External** ← Next.
3. **Contact Information**: جیمیل خودتون ← Next.
4. شرایط رو تیک بزنید ← **Create**.
5. از منوی سمت چپ برید به **Audience** ← بخش **Test users** ← **Add users** ← **جیمیلی که کانال زیرشه** رو بنویسید ← Save.
   - آدرس جیمیل رو بنویسید، نه اسم کانال.

## ۴. ساختن کلید ورود (OAuth client از نوع Desktop)

1. از منوی سمت چپ: **Clients** ← **Create client**.
2. **Application type**: گزینه‌ی **Desktop app**. نوع Web application نه، چون با ابزار ما کار نمی‌کنه.
3. اسم: `spoil-laptop` ← **Create**.
4. توی پنجره‌ای که باز می‌شه **Download JSON** رو بزنید. یه فایل `client_secret_....json` دانلود می‌شه.
   - اگه پنجره بسته شد: توی لیست Clients روی `spoil-laptop` بزنید ← آیکون دانلود.
5. فایل رو **بیرون از پوشه‌ی OpenMontage** بذارید، مثلاً توی پوشه‌ی `secrets` پروژه‌هاتون.
6. **محتوای فایل رو برای من نفرستید.** فقط بگید کجا گذاشتیدش.

## ۵. (پیشنهادی) جلوگیری از منقضی شدن هر ۷ روز

تا وقتی اپ توی حالت **Testing** باشه، گوگل اجازه‌ی ورود رو **هر ۷ روز باطل می‌کنه** و باید دوباره وارد بشید. برای اینکه همیشگی بشه:

1. ☰ ← Google Auth Platform ← **Audience** ← **Publish app** ← Confirm.
2. برای استفاده‌ی شخصی، بررسی گوگل (verification) لازم نیست.
3. از این به بعد، موقع ورود صفحه‌ی «Google hasn't verified this app» رو می‌بینید. چون اپ مال خودتونه، روی **Advanced** ← **Go to SPOIL publisher** بزنید.

## ۶. ورود یک‌باره

وقتی فایل JSON آماده شد، بگید تا من این دستور رو اجرا کنم. اگه هم خواستید، خودتون توی ترمینال از پوشه‌ی OpenMontage اجراش کنید:

```
.venv\Scripts\python.exe tools\publishers\youtube_api.py auth --client-secret "<مسیر فایل client_secret_....json>"
```

1. کروم باز می‌شه. با جیمیل کانال وارد بشید.
2. اگه پرسید کدوم کانال یا Brand Account، **اسپویل (@spoilfa)** رو انتخاب کنید.
3. اجازه‌ی «Manage your YouTube account» رو تیک بزنید ← **Continue**.
4. صفحه‌ای میاد که می‌گه «تمام شد»؛ ببندیدش.
5. ترمینال اسم و شناسه‌ی کانال رو نشون می‌ده و باید بنویسه `matches`.

کلیدها فقط توی فایل `.env` ذخیره می‌شن. این فایل توی گیت نمی‌ره و چیزی ازش چاپ نمی‌شه. بعد از این مرحله، فایل JSON دیگه لازم نیست، ولی یه نسخه ازش کنار رمزهاتون نگه دارید.

## بعدش چی می‌شه

هر دستور اول فقط **پیش‌نمایش** نشون می‌ده (چی آپلود می‌شه و چقدر سهمیه مصرف می‌کنه). فقط با `--apply` واقعاً چیزی روی یوتیوب نوشته می‌شه، و من بدون تأیید شما `--apply` نمی‌زنم.

| کار | دستور | سهمیه |
|---|---|---|
| زیرنویس‌ها (`NNN_subtitles_<زبان>.srt`) | `captions <شناسه‌ی ویدیو> 001` | ۴۰۰ برای هر زبان (+۵۱). اگه اون زبان از قبل روی ویدیو باشه، رد می‌شه |
| عنوان (گزینه‌ی A)، توضیحات، تگ‌ها، عنوان‌های ترجمه‌شده | `meta <شناسه> 001` | ۵۱ |
| کامنت اول | `comment <شناسه> 001` | ۵۲ |
| آپلود خود ویدیو (خصوصی) | `upload 001` | ۱۶۰۱ |

- سهمیه‌ی رایگان روزانه ۱۰٬۰۰۰ واحده و نیمه‌شب به وقت آمریکا (زمستون ۱۱:۳۰ و تابستون ۱۰:۳۰ صبح به وقت تهران) پر می‌شه. شش زیرنویس کا.گ.ب حدود ۲٬۴۵۰ واحد مصرف می‌کنه.
- **پین کردن کامنت از راه API ممکن نیست.** بعد از `comment`، توی Studio ← Comments یا زیر ویدیو ← ⋮ ← Pin، خودتون پینش کنید.
- **آپلود ویدیو از راه API فعلاً فقط خصوصی می‌شه.** ویدیوهایی که از پروژه‌ی تأییدنشده (بدون audit یوتیوب) آپلود بشن، قفل خصوصی می‌مونن. پس ویدیوهایی که باید عمومی بشن رو فعلاً **خودتون توی Studio آپلود کنید**، و زیرنویس و متن‌ها رو بسپرید به ابزار. درخواست audit رایگانه، ولی چند هفته طول می‌کشه.
- **شناسه‌ی ویدیو**: همون ۱۱ حرف آخر لینک (`youtu.be/XXXXXXXXXXX`)، یا توی Studio از آدرس `studio.youtube.com/video/XXXXXXXXXXX/edit`. خود لینک کامل رو هم می‌شه داد.
- شناسه و لینک هر ویدیو، و هر کاری که ابزار انجام بده، توی جدول «وضعیت آپلود» در `SPOIL\README.md` ثبت می‌شه.
