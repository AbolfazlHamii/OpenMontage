# راه‌اندازی جیمیل و کانال یوتیوب

این کارها رو خودتون انجام می‌دید، چون ساختن اکانت و وارد کردن رمز با خود شماست. هر مرحله که تموم شد، توی چت بگید تا بریم سراغ مرحله‌ی بعد.

## قبل از شروع: VPN

- از ایران، گوگل خیلی از صفحه‌ها رو با خطای 403 می‌بنده و یوتیوب هم فیلتره. پس **همه‌ی این مراحل با v2rayN روشن** انجام می‌شه (پراکسی سیستم، `127.0.0.1:10808`).
- **کشور VPN رو وسط کار عوض نکنید.** هم موقع ساختن اکانت و هم چند روز اول، از همون سرور همیشگی (الان هلند) استفاده کنید. اگه گوگل ببینه یه اکانت تازه هر چند دقیقه از یه کشور وارد می‌شه، قفلش می‌کنه یا مدام تأیید می‌خواد.
- بهتره توی کروم یه **پروفایل جدا** برای کانال بسازید (آیکون آدمک بالای کروم ← Add). این‌طوری اکانت کانال با اکانت شخصی‌تون قاطی نمی‌شه.
- تست ۱۴۰۵/۰۸/۱۵ (2026-11-06) از همین لپ‌تاپ، با VPN هلند: صفحه‌ی ثبت‌نام گوگل و یوتیوب باز می‌شن، ولی کنسول Google Cloud با 403 بسته‌ست. برای ساختن جیمیل و کانال این مشکلی نیست؛ فقط برای مرحله‌ی آپلود خودکار (بخش ۵) مهمه.

## ۱. ساختن جیمیل

1. VPN روشن ← توی کروم برید به `accounts.google.com/signup`.
2. «For my personal use» (برای استفاده‌ی شخصی).
3. **اسم**: هر اسمی. اسم کانال جداست و بعداً گذاشته می‌شه (بخش ۲)، پس لازم نیست اینجا اسم کانال رو بنویسید.
4. **تاریخ تولد**: تاریخ واقعی. اکانت زیر ۱۸ سال محدودیت داره.
5. **آدرس جیمیل**: یه چیز ساده و خنثی، مثلاً اسم کانال + `studio`. **این آدرس بعداً عوض نمی‌شه.**
6. **رمز**: یه رمز قوی و جدید که جای دیگه استفاده نکرده باشید. خودتون توی `projects-hub\secrets\secrets.md`، جدول «اکانت‌ها»، بنویسیدش. لازم نیست به من بگید.
7. **شماره‌ی تلفن**: اگه خواست، شماره‌ی خودتون (‎+98). گاهی گوگل شماره‌ی ایرانی رو قبول نمی‌کنه («This phone number cannot be used for verification»). در این صورت:
   - چند ساعت بعد دوباره امتحان کنید (با همون VPN)؛
   - شماره‌ی مجازی خریداری‌شده نذارید؛ اکانت‌هایی که با این شماره‌ها ساخته می‌شن زیاد قفل می‌شن.
8. **ایمیل بازیابی**: ایمیل شخصی خودتون.
9. بعد از ساخت، فوراً **تأیید دومرحله‌ای (2-Step Verification)** رو روشن کنید: `myaccount.google.com/security`. کانال‌های یوتیوب زیاد هک می‌شن. **کدهای پشتیبان (Backup codes)** رو بگیرید و کنار رمز توی `secrets.md` بنویسید.

گوگل ممکنه کشور اکانت رو از روی VPN «هلند» بذاره. اشکالی نداره.

## ۲. ساختن کانال (Brand Account)

کانال Brand Account یعنی کانال اسم خودش رو داره، نه اسم اکانت. بعداً هم می‌شه یه نفر دیگه (مثلاً تدوینگر) رو بدون دادن رمز به کانال اضافه کرد.

1. VPN روشن ← با همین جیمیل وارد `youtube.com` بشید.
2. برید به `youtube.com/channel_switcher` ← **Create a channel**.
   - از دکمه‌ی «Create a channel» توی منوی پروفایل استفاده نکنید؛ اون یه کانال شخصی با اسم اکانت می‌سازه.
3. اسم کانال رو بنویسید ← Create.
4. توی YouTube Studio (`studio.youtube.com`) ← Customization:
   - **Handle**: هندل لاتین (مثلاً ‎`@spoilfa`). اگه گرفته شده باشه همونجا می‌گه.
   - عکس پروفایل و بنر رو بعداً با هم آماده می‌کنیم.

## ۳. تأیید شماره (برای ویدیوی بلندتر از ۱۵ دقیقه و تامبنیل دلخواه)

1. VPN روشن ← `youtube.com/verify`.
2. کشور: Iran، روش: پیامک (Text me) یا تماس صوتی (Call me)، شماره‌ی خودتون.
3. کدی که اومد رو وارد کنید.
4. اگه شماره‌ی ایرانی رو قبول نکرد: یه بار با «Call me» امتحان کنید. اگه باز هم نشد، به من بگید؛ بخش ۴ هنوز راه‌های دیگه داره.

بعد از این، توی Studio ← Settings ← Channel ← **Feature eligibility**، بخش «Features that require phone verification» باید Enabled باشه.

## ۴. روشن کردن «Advanced features» (برای Test & Compare)

Test & Compare (آزمایش ۳ تامبنیل یا ۳ عنوان) فقط با Advanced features کار می‌کنه.

1. Studio ← Settings ← Channel ← Feature eligibility ← **Advanced features** ← Access features.
2. یوتیوب یکی از این راه‌ها رو می‌ده:
   - **تأیید با ویدیوی سلفی**: یه ویدیوی کوتاه از صورت، با اپ یوتیوب روی گوشی؛
   - **کارت شناسایی معتبر**؛
   - **سابقه‌ی کانال**: بعد از مدتی فعالیت بدون اخطار، خودبه‌خود روشن می‌شه.
3. هر کدوم رو که خودتون راحتید انتخاب کنید. فقط با مدارک و صورت خودتون؛ مدرک یا اکانت کس دیگه نه.

## ۵. آپلود خودکار (بعد از ساختن کانال)

ابزارش `tools/publishers/youtube_api.py` هست. مراحل Google Cloud توی `docs/fa/YOUTUBE_API_SETUP.md` توضیح داده شده. خلاصه: زیرنویس، عنوان، توضیحات، تگ‌ها و کامنت خودکار می‌رن. ولی خود ویدیو تا وقتی پروژه audit یوتیوب رو نگذرونده فقط خصوصی آپلود می‌شه، پس ویدیوی عمومی رو خودتون توی Studio آپلود کنید. همه‌ی متن‌ها توی `SPOIL/NNN_.../` آماده‌ست.
